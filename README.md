## 💻 Example Practice

Some of the problems and concepts I practice include:

```cpp
// Finding the second largest element

int mx = INT_MIN;
int second = INT_MIN;

for (int x : arr) {
    if (x > mx) {
        second = mx;
        mx = x;
    }
    else if (x > second && x != mx) {
        second = x;
    }
}
```

The purpose is not just to make the code work, but to understand **why it works, how it works, and how it can be improved.**
